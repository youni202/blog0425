# Youni's Blog

GitHub Pages blog using the [Just the Docs](https://github.com/just-the-docs/just-the-docs) Jekyll theme.

Live site: <https://youni202.github.io/blog0425/>

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/blog0425/>.

## Writing posts

Create a Markdown file in `_posts/` with this filename format:

```txt
YYYY-MM-DD-post-title.md
```

Use `_templates/post.md` as a starting point.
