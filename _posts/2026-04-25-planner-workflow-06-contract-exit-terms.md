# 6. 수행사와 다툼 없이 손절 가능한 계약 조건

프로젝트에서 수행사를 바꾸거나 계약을 중단해야 하는 상황은 누구에게나 부담스럽습니다. 그래서 계약 단계에서 감정이 아니라 기준으로 이야기할 수 있는 조건을 만들어두는 것이 중요합니다.

핵심은 단계별 산출물과 검수 기준을 계약에 연결하는 것입니다.

## 단계별 용역 수행 의무

계약은 전체 금액만 적는 것보다 단계별 결과물과 검수 기준을 나누는 편이 안전합니다.

| 단계 | 대표 산출물 | 검수 기준 |
| --- | --- | --- |
| 1차 | 화면설계서, 프로토타입 | 주요 사용자 흐름과 화면 정책 확인 |
| 2차 | 핵심 기능 개발 | 신청, 확인, 승인 등 핵심 기능 동작 |
| 3차 | 관리 기능 개발 | 관리자 화면, 공유/관리 기능 동작 |
| 4차 | 오픈 안정화 | 오픈 후 정상 작동과 오류 대응 |

## 단계 검수와 대금 지급 연결하기

단계별 검수 기준을 통과해야 다음 단계로 넘어가고, 해당 단계 용역비를 지급하는 구조를 계약서에 반영할 수 있습니다.

| 조건 | 의미 |
| --- | --- |
| 산출물 제출 | 수행사가 단계별 결과물을 제출 |
| 검수 진행 | 고객 또는 발주사가 기준에 따라 확인 |
| 보완 요청 | 미흡한 항목을 일정 내 수정 요청 |
| 검수 완료 | 기준 충족 시 다음 단계 진행 |
| 미통과 시 조치 | 대금 지급 보류, 계약 해제 조건 검토 |

## 계약서에 남겨야 할 문장

문장을 쓸 때는 감정적인 표현보다 객관적인 기준을 중심에 둡니다.

| 애매한 표현 | 더 나은 표현 |
| --- | --- |
| 품질이 낮으면 계약을 해지한다 | 검수 기준을 충족하지 못하고 지정 기간 내 보완되지 않을 경우 계약 해제를 협의한다 |
| 제대로 만들지 않으면 지급하지 않는다 | 단계별 산출물 검수 완료 후 해당 단계 용역비를 지급한다 |
| 일정이 늦으면 책임진다 | 지연 사유, 영향 범위, 복구 일정을 서면으로 제출한다 |

## 갈등을 줄이는 운영 방식

| 운영 원칙 | 설명 |
| --- | --- |
| 기준을 먼저 공유 | 검수 기준을 착수 초기에 합의 |
| 단계별 확인 | 마지막에 몰아서 판단하지 않기 |
| 보완 기한 명시 | 수정 요청 후 처리 기한을 정하기 |
| 기록 남기기 | 메일, 회의록, 이슈 목록으로 근거 확보 |
| 중단 조건 합의 | 어느 경우에 멈출 수 있는지 문서화 |

{: .warning }
계약 조건은 실제 법률 검토가 필요한 영역입니다. 이 글은 실무 문서 관점의 정리이며, 중요한 계약은 반드시 법무 검토를 거쳐야 합니다.

## 단계별 산출물 예시

계약서에 “산출물 일체”라고만 쓰면 서로 기대하는 결과물이 달라질 수 있습니다. 단계별로 무엇을 받는지 구체화해야 합니다.

| 단계 | 산출물 | 확인 방법 |
| --- | --- | --- |
| 분석/설계 | 요구사항 정리서, IA, 화면설계서, 정책 정의 | 고객 검토 회의와 승인 메일 |
| 디자인 | 주요 화면 시안, 디자인 가이드, 이미지 원본 | 시안 리뷰와 수정 반영 확인 |
| 개발 | 사용자 기능, 관리자 기능, 연동 기능 | 검수 시나리오 기반 테스트 |
| 오픈 | 배포 결과, 운영 계정, 매뉴얼, 오류 처리 목록 | 오픈 체크리스트와 인수 확인 |

## 중단 조건을 감정이 아니라 기준으로 쓰기

수행사를 바꾸는 상황은 대부분 감정이 먼저 올라옵니다. 그래서 계약서와 회의록에는 감정 표현이 아니라 판단 기준이 있어야 합니다.

| 판단 기준 | 문서화 방법 |
| --- | --- |
| 일정 지연 | 지연 일수, 지연 사유, 복구 일정 제출 여부 |
| 품질 미달 | 검수 항목 중 미통과 항목 수와 보완 결과 |
| 커뮤니케이션 불이행 | 정기 보고 누락, 회의 불참, 요청 미응답 기록 |
| 범위 불일치 | 계약 범위 대비 미제공 산출물 목록 |

## 회의록에 남길 문장

| 상황 | 문장 예시 |
| --- | --- |
| 보완 요청 | 금일 검수 결과 미충족 항목은 총 12건이며, 수행사는 4월 30일까지 수정 계획을 공유한다 |
| 일정 지연 | 최초 합의 일정 대비 5영업일 지연되었으며, 지연 영향 범위와 복구 일정을 별도 문서로 제출한다 |
| 단계 보류 | 2차 단계 검수 완료 전까지 3차 범위 착수와 대금 지급은 보류한다 |
| 계약 조정 | 보완 기간 내 기준 충족이 어려울 경우 잔여 범위 조정 또는 계약 해제를 협의한다 |

## PM이 챙길 체크리스트

| 확인 | 항목 |
| --- | --- |
|  | 단계별 산출물 이름이 계약서나 별첨에 적혀 있는가 |
|  | 검수 기준과 보완 기한이 정해져 있는가 |
|  | 대금 지급 조건이 단계 완료와 연결되어 있는가 |
|  | 계약 해제 또는 범위 조정 조건이 법무 검토를 거쳤는가 |
|  | 모든 보완 요청이 메일이나 회의록으로 남아 있는가 |
